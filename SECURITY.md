# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes |
| &lt; 1.0  | No |

## Reporting a Vulnerability

Please report security issues privately. Do **not** open a public GitHub issue for vulnerabilities.

**Preferred:** [GitHub Security Advisory](https://github.com/rsebany/GrayMatter/security/advisories/new)

**Email:** romualdosebany@gmail.com

Include when possible:

- Vulnerability type and impact
- Affected paths / commit or tag
- Steps to reproduce
- Proof-of-concept (if available)

## Response

We aim to acknowledge reports within **48 hours** and follow up with a remediation plan and timeline.

## Local development credentials

Seeded Docker logins and default JWT/DB values in `.env.example` are for **local development only**. Change them before any shared or production deployment.
